# Smart Grid Real-Time Load Monitoring using MLflow

## Project Overview
This project predicts Grid Supply (kW) in a Smart Grid environment using Machine Learning and MLflow.

## Dataset
Smart Grid Energy Dataset

## Problem Statement
Predict Grid Supply (kW) using electrical and environmental variables.
